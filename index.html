ONGOING RESEARCH

Failure-Aware Agent Framework (FAAF)

Autonomous Agent Reliability & Failure Recovery

Researching runtime failure detection in long-horizon autonomous systems. Developing a novel taxonomy of LLM agent failures — infinite loops, tool misuse, hallucinated execution success — and implementing recovery strategies including state rollbacks and self-reflection loops.

Wireless Channel Prediction with AI

Deep Learning for Communication Networks

Replacing traditional mathematical predictors with sequence-to-sequence deep learning architectures (LSTM/GRU encoder-decoders) mapped directly to hardware SDR metrics (SNR/RSSI). Optimizing transmission parameters asynchronously to lower network latency.
