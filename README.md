# Vaibhavi Singh — Portfolio

Personal portfolio website showcasing AI systems engineering, research, and projects.

## Live URL
- **Production**: [https://portfolio-phi-eight-99.vercel.app/](https://portfolio-phi-eight-99.vercel.app/)

## Tech Stack
- HTML5
- CSS3 (Responsive design, custom properties, glassmorphism)
- Vanilla JavaScript

## Local Development
To run the portfolio locally, open `index.html` directly in a browser or run a lightweight local static server:

```bash
# Using Python
python3 -m http.server 3000

# Using npx
npx serve .
```

## Deployment
Hosted and deployed on [Vercel](https://vercel.com/). Connecting this repository to Vercel enables automatic deployments on push to the `main` branch.
